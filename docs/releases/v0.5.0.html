Добавлено

Графический пульт

Dashboard, мастер добавления VPS, ключи, QR-коды и настройки профилей. GUI вызывает серверные команды по SSH, а не подменяет Xrayebator.

Семь маршрутов в одном профиле

Новый HAPP schema-v3 профиль объединяет TCP Vision, uTLS Firefox, XUDP, TCP mux, gRPC и два XHTTP-варианта под одной ссылкой подписки.

Управление без ручного JSON

Профили можно создавать и удалять, а fingerprint, SNI и порт менять из Server Settings. Низкоуровневые CLI-команды остаются доступными.

Что стало надёжнее

Сервер

Backup перед изменением

Runtime-операции проходят через сохранение, проверку конфигурации Xray и rollback при ошибке, чтобы не оставлять сервер на заведомо невалидном конфиге.

safety
Установка

Можно продолжить прерванный процесс

Флаги --check, --resume и --fresh помогают понять состояние десяти шагов установки и безопасно продолжить работу.

lifecycle
Совместимость

IPv6-сценарии стали аккуратнее

Установщик учитывает IPv6-адреса, DNS fallback и формат URL. Автоматический public IP-TLS для IPv6-only VPS не заявляется: используйте доменный TLS с достижимой A/AAAA-записью.

networking
Проверки

24 Bash-теста и Electron unit-тесты

Проверяются миграции, HAPP, VLESS-ссылки, firewall, SNI/port-change, SSH-доступ, JSON и subscription parsing.

CI

Изменения границ

  • Активное десктоп-приложение теперь находится в src/: это Electron + React + TypeScript.
  • PySide6-клиент перенесён в gui-legacy/ и сохранён как архивный отдельный проект.
  • GUI не отображает весь терминальный menu surface: bypass, probe-test, revoke, happ-setup, cascade, self-steal и service logs остаются в CLI.

Известные ограничения

  • Subscription URL и VLESS-ссылки нужны GUI для работы и должны рассматриваться как bearer credentials.
  • Полного end-to-end теста упакованного Electron-приложения пока нет.
  • Последующий аудит нашёл задачи hardening для safe_jq_write, lifecycle rollback, JSON escaping и проверок существующих inbound. Этот релиз не заявляет их исправленными.
  • Локальная Windows-среда не является источником истины для POSIX-теста с /bin/sh; проверка выполняется на Linux CI.
  • Для IPv6-only VPS автоматический public IP-TLS не заявляется: настройте доменный TLS с достижимой A/AAAA-записью.
  • Linux-файл — Xrayebator-0.5.0-linux.AppImage: его можно сделать исполняемым и запускать без apt-установки. Snap не публикуется. Для macOS публикуются Apple Silicon DMG и ZIP, который нужен встроенному автообновлению.

Как обновиться

  1. Скачайте пакет своей ОС из GitHub Release v0.5.0.
  2. Установите GUI поверх предыдущей версии и откройте сохранённую карточку VPS.
  3. Для сервера используйте sudo xrayebator update main или полный sudo xrayebator-update main, затем проверьте Xray, DNS и subscription endpoint.
  4. После обновления сервера обновите подписку в клиенте и переподключитесь.
